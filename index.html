Projets réalisés

Sphere Solar : supervision IoT d’une centrale photovoltaïque

PFE, STEG Metlaoui, 2026

Une solution complète pour suivre une installation photovoltaïque raccordée au réseau et repérer automatiquement les pertes de production, comme l’encrassement des panneaux.

  • 10,8 kWcinstallation dimensionnée
  • 18modules, onduleur Solis 12 kW
  • 88 %ratio de performance (PVsyst)
  • Firmware ESP32 en C/C++ qui lit l’onduleur en RS485 / Modbus RTU et transmet les mesures en MQTT.
  • Serveur FastAPI / SQLite avec API REST, WebSocket et authentification JWT.
  • Application mobile React Native / Expo avec alertes, rapports PDF et assistant d’analyse basé sur un LLM.
  • Comparaison quotidienne de la production mesurée à la référence PVsyst pour détecter les pertes lentes.
  • Chaîne validée de bout en bout en simulation (Wokwi), broker sécurisé (TLS, ACL) prêt pour le déploiement.
  • ESP32
  • Modbus RTU
  • MQTT
  • FastAPI
  • React Native
  • PVsyst

Projects

Sphere Solar: IoT monitoring for a solar PV plant

Final-year project, STEG Metlaoui, 2026

A complete solution to monitor a grid-connected solar installation and automatically detect production losses, such as panel soiling.

  • 10.8 kWpsystem sized
  • 18modules, Solis 12 kW inverter
  • 88%performance ratio (PVsyst)
  • ESP32 firmware in C/C++ that reads the inverter over RS485 / Modbus RTU and publishes measurements over MQTT.
  • FastAPI / SQLite server with a REST API, WebSocket streaming and JWT authentication.
  • React Native / Expo mobile app with alerts, PDF reports and an LLM-based analysis assistant.
  • Daily comparison of measured production against the PVsyst reference to detect gradual losses.
  • End-to-end chain validated in simulation (Wokwi), with a secured broker (TLS, ACL) ready for deployment.
  • ESP32
  • Modbus RTU
  • MQTT
  • FastAPI
  • React Native
  • PVsyst
